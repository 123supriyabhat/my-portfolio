🌸 E-Commerce Flower Shop

Project Type: Mini Project

About the Project

This project is a simple flower-shopping website designed to present flowers through an online shopping-style interface.

Objective

To learn how to structure and style a website and create an attractive layout for displaying flower products.

Technologies Used

  • HTML — webpage structure
  • CSS — design, layout, colours and styling

Key Learning

  • Creating webpages using HTML
  • Styling pages using CSS
  • Organizing content and improving visual presentation

Purpose

The project demonstrates basic frontend development skills through a flower-shopping website concept.
